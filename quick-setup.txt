🚀 LEETCODE SYNC - QUICK DEPLOYMENT GUIDE

STEP 1: FREE DATABASE (Neon.tech)
- Go to: https://neon.tech
- Sign up with GitHub
- Create database "leetcode_sync"
- Copy connection string
- Format: postgresql://username:password@host/database

STEP 2: GOOGLE SHEETS API
- Go to: https://console.cloud.google.com
- New project: "leetcode-sync-api"
- Enable Google Sheets API
- Create Service Account
- Download JSON key
- Create Google Sheet
- Share sheet with service account email

STEP 3: VERCEL DEPLOYMENT
- Go to: https://vercel.com
- Import from Git (or drag & drop folder)
- Add environment variables:
  * GOOGLE_CREDENTIALS_JSON
  * GOOGLE_SHEET_ID
  * DATABASE_URL
  * LEETCODE_USER

STEP 4: TEST
- Visit your Vercel URL
- Test /trigger-sync endpoint
- Check Google Sheets for data

🎯 TOTAL TIME: ~10 minutes
✅ RESULT: Fully working LeetCode sync system!
